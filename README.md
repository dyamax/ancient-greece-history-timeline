# Ancient Greece Timeline

A small educational website presenting a visual timeline of major events and developments in ancient Greek history. The home page introduces each topic, and the individual pages provide more detail through interactive sections.

## Topics

- [The Trojan War](The-Trojan-War.html)
- [The First Greek Alphabet](Alphabet.html)
- [The First Olympic Games](First-Olympic-Games.html)
- [The Greco-Persian Wars](Greco-Persian-Wars.html)
- [The Peloponnesian War](peloponnesian-war.html)

## Open the website

Open `index.html` in a web browser. No installation or build step is required. For local development, you can also serve the project directory with any static file server.

## Project files

- `index.html` - timeline home page
- `*.html` - individual history topic pages
- `style.css` - shared layout, styling, and image backgrounds
- `script.js` - interactive topic sections
- `photo/` - images used throughout the pages
- `Documentation/` - project documentation and supporting materials
